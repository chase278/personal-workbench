# 个人工作台（脱敏副本）

此副本已移除敏感信息，可在新设备上继续部署使用。

## 文件说明

- `index.html`：个人工作台前端页面，数据默认保存在浏览器 localStorage，支持通过本地签名服务同步到腾讯云 COS。
- `cos-server/server.js`：本地 COS 签名服务，负责签发预签名 URL，前端不直接暴露密钥。
- `cos-server/package.json`：Node.js 依赖描述。

## 在新设备上启动

1. 安装 Node.js 依赖
   ```bash
   cd cos-server
   npm install
   ```

2. 配置腾讯云 COS 密钥（三选一）
   - 编辑 `cos-server/server.js` 顶部的 `SECRET_ID`、`SECRET_KEY`、`BUCKET`、`REGION`。
   - 或设置环境变量：
     ```bash
     export COS_SECRET_ID=你的SecretId
     export COS_SECRET_KEY=你的SecretKey
     export COS_BUCKET=你的bucket名
     export COS_REGION=你的地域
     ```
   - 建议使用环境变量，避免密钥写入文件。

3. 启动签名服务
   ```bash
   npm start
   # 或
   node server.js
   ```

4. 用浏览器打开 `index.html` 即可使用。

## 已完成任务的折叠与归档（周 / 月）

工作台对「本周计划」和「本月计划」中已完成的任务提供了**自动归档 + 折叠展示**能力，避免"已完成"列表无限增长：

### 自动归档规则

- **本周计划（按周归档）**：每周一 00:00 起算新的一周，上一周内完成的任务会在打开页面时自动移出"本周已完成"，按 ISO 周分组归档到下方的 **历史归档（按周折叠）** 区域，分组标签形如 `2026-W38`。
- **本月计划（按月归档）**：每月 1 日 00:00 起算新的一月，上月完成的任务自动归档到 **历史归档（按月折叠）** 区域，分组标签形如 `2026-09`。
- 归档在打开页面时自动触发，且是**幂等**的——重复刷新不会产生重复归档；从云端同步回旧数据后也会重新执行归档，保证一致。
- 归档时机依据任务完成时记录的 `completedAt` 时间戳（精确到分钟），而非勾选时刻。

### 折叠展示说明

- 历史归档区的外层是一个总开关（`历史归档（按周/月折叠）`），可以整体收起或展开。
- 归档区内部按周/月分组，**每组独立折叠**：点击组头（含下拉三角、周/月标签、`完成 N 项` 计数、日期区间）即可展开或收起该组。
- **默认展开最近的 2 组**，更早的组默认收起；之后以你手动展开/收起的状态为准。
- 各组的折叠/展开状态仅为页面级 UI 状态，**不写入数据、不参与云同步**——不同设备各自记忆，互不影响。
- 归档数据保存在任务数据的 `history` 字段中，随 localStorage 和云端同步（`/api/state`）一起持久化，跨设备可见。

## 安全提醒

- 本副本中的 `server.js` 已抹去原 SecretId、SecretKey 和 Bucket 名，请使用新的密钥对进行配置。
- 如果原密钥已经泄漏（例如曾随文件发送或上传），请立即到腾讯云控制台【访问管理 > API 密钥管理】中禁用或删除该密钥，并创建新密钥。
